Code Defense

Email is required because it provides a written confirmation channel. Phone is optional to minimize data collection while still allowing urgent contact. ZIP is a select to prevent free-text errors. Radio labels use matching for and id values. aria-describedby connects help text to each control. The date minimum is set to today to avoid past dates.
